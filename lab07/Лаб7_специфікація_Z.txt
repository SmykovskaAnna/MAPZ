Лабораторна робота №7. Z-специфікація HabitTracker
Фрагмент: «Звичка» та «ЗаписВиконання».

[HABIT_ID, RECORD_ID, PERIOD_ID]

СТАН ::= чернетка | очікує | виконано | призупинена | архівована
РЕЗУЛЬТАТ ::= успіх | звичкаВідсутня | станЗаборонений | записВжеЄ
             | періодНеПоточний | ідентифікаторЗайнятий

максЗаписівЗаПеріод == 1

┌─ HabitTracker ─────────────────────────────────────────────────────
│ стан       : HABIT_ID ⇸ СТАН
│ період     : HABIT_ID ⇸ PERIOD_ID
│ записи     : (HABIT_ID × PERIOD_ID) ⤔ RECORD_ID
│ доПаузи    : HABIT_ID ⇸ СТАН
├─────────────────────────────────────────────────────────────────────
│ dom стан = dom період
│ dom записи ⊆ dom стан × PERIOD_ID
│ ∀ h : dom стан • стан(h) = виконано ⇒ (h,період(h)) ∈ dom записи
│ стан(h) = призупинена ⇔ h ∈ dom доПаузи  (для кожного h : dom стан)
│ dom доПаузи ⊆ dom стан
│ ∀ h : dom доПаузи • доПаузи(h) ∈ {очікує, виконано}
└─────────────────────────────────────────────────────────────────────

«записи» є частковою ін'єкцією від пари (звичка, період) до ID запису.
Вона задає максимум один запис для пари та не дозволяє повторно
використовувати ID запису.

┌─ ПочатковийСтан ────────────────────────────────────────────────────
│ HabitTracker'
├─────────────────────────────────────────────────────────────────────
│ стан' = ∅ ∧ період' = ∅ ∧ записи' = ∅ ∧ доПаузи' = ∅
└─────────────────────────────────────────────────────────────────────

┌─ СтворитиЗвичку ────────────────────────────────────────────────────
│ ΔHabitTracker; h? : HABIT_ID; p? : PERIOD_ID
├─────────────────────────────────────────────────────────────────────
│ h? ∉ dom стан
│ стан' = стан ∪ {h? ↦ чернетка} ∧ період' = період ∪ {h? ↦ p?}
│ записи' = записи ∧ доПаузи' = доПаузи
└─────────────────────────────────────────────────────────────────────

┌─ Активувати ───────────────────────────────────────────────────────
│ ΔHabitTracker; h? : HABIT_ID
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) = чернетка
│ стан' = стан ⊕ {h? ↦ очікує} ∧ період' = період
│ записи' = записи ∧ доПаузи' = доПаузи
└─────────────────────────────────────────────────────────────────────

┌─ ПозначитиВиконаною ────────────────────────────────────────────────
│ ΔHabitTracker; h? : HABIT_ID; r? : RECORD_ID; p? : PERIOD_ID
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) = очікує ∧ p? = період(h?)
│ (h?,p?) ∉ dom записи ∧ r? ∉ ran записи
│ стан' = стан ⊕ {h? ↦ виконано}
│ записи' = записи ∪ {(h?,p?) ↦ r?}
│ період' = період ∧ доПаузи' = доПаузи
└─────────────────────────────────────────────────────────────────────

┌─ НовийПеріод ───────────────────────────────────────────────────────
│ ΔHabitTracker; h? : HABIT_ID; pНовий? : PERIOD_ID
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) = виконано ∧ pНовий? ≠ період(h?)
│ стан' = стан ⊕ {h? ↦ очікує} ∧ період' = період ⊕ {h? ↦ pНовий?}
│ записи' = записи ∧ доПаузи' = доПаузи
└─────────────────────────────────────────────────────────────────────

┌─ Призупинити ───────────────────────────────────────────────────────
│ ΔHabitTracker; h? : HABIT_ID
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) ∈ {очікує, виконано}
│ стан' = стан ⊕ {h? ↦ призупинена}
│ доПаузи' = доПаузи ∪ {h? ↦ стан(h?)}
│ період' = період ∧ записи' = записи
└─────────────────────────────────────────────────────────────────────

┌─ Відновити ─────────────────────────────────────────────────────────
│ ΔHabitTracker; h? : HABIT_ID
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom доПаузи
│ стан' = стан ⊕ {h? ↦ доПаузи(h?)}
│ доПаузи' = {h?} ⩤ доПаузи ∧ період' = період ∧ записи' = записи
└─────────────────────────────────────────────────────────────────────

┌─ Архівувати ────────────────────────────────────────────────────────
│ ΔHabitTracker; h? : HABIT_ID
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) ∈ {очікує, виконано}
│ стан' = стан ⊕ {h? ↦ архівована}
│ період' = період ∧ записи' = записи ∧ доПаузи' = доПаузи
└─────────────────────────────────────────────────────────────────────

┌─ ВідновитиЗАрхіву ──────────────────────────────────────────────────
│ ΔHabitTracker; h? : HABIT_ID; pНовий? : PERIOD_ID
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) = архівована ∧ pНовий? ≠ період(h?)
│ стан' = стан ⊕ {h? ↦ очікує} ∧ період' = період ⊕ {h? ↦ pНовий?}
│ записи' = записи ∧ доПаузи' = доПаузи
└─────────────────────────────────────────────────────────────────────

┌─ ОтриматиПрогрес ───────────────────────────────────────────────────
│ ΞHabitTracker; h? : HABIT_ID; прогрес! : 0 .. 100
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан
│ прогрес! = (if стан(h?) = виконано then 100 else 0)
└─────────────────────────────────────────────────────────────────────

┌─ ПомилкаВідсутняЗвичка ─────────────────────────────────────────────
│ ΞHabitTracker; h? : HABIT_ID; r? : RECORD_ID; p? : PERIOD_ID
│ результат! : РЕЗУЛЬТАТ
├─────────────────────────────────────────────────────────────────────
│ h? ∉ dom стан ∧ результат! = звичкаВідсутня
└─────────────────────────────────────────────────────────────────────

┌─ УспішнеПозначення ─────────────────────────────────────────────────
│ ΔHabitTracker; h? : HABIT_ID; r? : RECORD_ID; p? : PERIOD_ID
│ результат! : РЕЗУЛЬТАТ
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) = очікує ∧ p? = період(h?)
│ (h?,p?) ∉ dom записи ∧ r? ∉ ran записи
│ стан' = стан ⊕ {h? ↦ виконано}
│ записи' = записи ∪ {(h?,p?) ↦ r?}
│ період' = період ∧ доПаузи' = доПаузи ∧ результат! = успіх
└─────────────────────────────────────────────────────────────────────

┌─ ПомилкаСтану ──────────────────────────────────────────────────────
│ ΞHabitTracker; h? : HABIT_ID; r? : RECORD_ID; p? : PERIOD_ID
│ результат! : РЕЗУЛЬТАТ
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) ≠ очікує ∧ результат! = станЗаборонений
└─────────────────────────────────────────────────────────────────────

┌─ ПомилкаПовтору ────────────────────────────────────────────────────
│ ΞHabitTracker; h? : HABIT_ID; r? : RECORD_ID; p? : PERIOD_ID
│ результат! : РЕЗУЛЬТАТ
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) = очікує ∧ (h?,p?) ∈ dom записи
│ p? = період(h?)
│ результат! = записВжеЄ
└─────────────────────────────────────────────────────────────────────

┌─ ПомилкаПеріоду ────────────────────────────────────────────────────
│ ΞHabitTracker; h? : HABIT_ID; r? : RECORD_ID; p? : PERIOD_ID
│ результат! : РЕЗУЛЬТАТ
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) = очікує ∧ p? ≠ період(h?)
│ результат! = періодНеПоточний
└─────────────────────────────────────────────────────────────────────

┌─ ПомилкаІдентифікатора ─────────────────────────────────────────────
│ ΞHabitTracker; h? : HABIT_ID; r? : RECORD_ID; p? : PERIOD_ID
│ результат! : РЕЗУЛЬТАТ
├─────────────────────────────────────────────────────────────────────
│ h? ∈ dom стан ∧ стан(h?) = очікує ∧ p? = період(h?)
│ (h?,p?) ∉ dom записи ∧ r? ∈ ran записи
│ результат! = ідентифікаторЗайнятий
└─────────────────────────────────────────────────────────────────────

ПозначитиВиконаноюПовна == УспішнеПозначення
  ∨ ПомилкаВідсутняЗвичка ∨ ПомилкаСтану ∨ ПомилкаПовтору
  ∨ ПомилкаПеріоду ∨ ПомилкаІдентифікатора

Позначення: dom — область визначення; ran — область значень; ⇸ — часткова
функція; ⤔ — часткова ін'єкція; ℙ — множина; ⊕ — перевизначення; Δ — зміна стану; Ξ — стан
незмінний; ? — вхід; ! — вихід.
