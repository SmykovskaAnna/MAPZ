# Словник предметної області HabitTracker

## 1. Загальні поняття

| Термін | Ідентифікатор | Опис |
|---|---|---|
| HabitTracker | HabitTracker | Інтерактивний вебзастосунок для формування, моніторингу та аналітики персональних звичок |
| Звичка | Habit | Регулярна дія, яку користувач прагне виконувати для досягнення певної мети |
| Користувач | User | Особа, яка взаємодіє із системою HabitTracker |
| Гість | Guest | Неавторизований користувач, який може зареєструватися або увійти в систему |
| Зареєстрований користувач | RegisteredUser | Користувач, який має обліковий запис і доступ до персональних функцій системи |
| Профіль | Profile | Сукупність персональних даних і налаштувань користувача |

## 2. Керування звичками

| Термін | Ідентифікатор | Опис |
|---|---|---|
| Створення звички | CreateHabit | Додавання нової звички до особистого списку користувача |
| Редагування звички | EditHabit | Зміна параметрів уже створеної звички |
| Видалення звички | DeleteHabit | Видалення звички зі списку користувача |
| Періодичність | Frequency | Визначає, як часто користувач планує виконувати звичку |
| Виконання звички | HabitCompletion | Факт виконання певної звички користувачем за конкретний день або період |
| Нотатка | Note | Додаткова текстова інформація, яку користувач може залишити під час фіксації виконання звички |

## 3. Моніторинг та аналітика

| Термін | Ідентифікатор | Опис |
|---|---|---|
| Прогрес | Progress | Інформація про досягнення користувача у виконанні звичок |
| Статистика | Statistics | Узагальнені показники виконання звичок за певний період |
| Історія виконання | HabitHistory | Записи про виконання або невиконання звичок у минулому |

## 4. Нагадування

| Термін | Ідентифікатор | Опис |
|---|---|---|
| Нагадування | Reminder | Повідомлення, яке допомагає користувачу не забувати про заплановану звичку |
| Налаштування нагадувань | ReminderSettings | Параметри часу та умов отримання нагадувань |
| Сервіс сповіщень | NotificationService | Зовнішній сервіс, який забезпечує надсилання сповіщень користувачу |

## 5. Правила використання термінів

1. Для позначення системи в усіх лабораторних роботах використовується назва `HabitTracker`.
2. Для позначення користувача використовується ідентифікатор `User`.
3. `Guest` і `RegisteredUser` є спеціалізаціями актора `User`.
4. Для позначення звички використовується термін `Habit`.
5. Для позначення факту виконання звички використовується термін `HabitCompletion`.
6. Назви класів, сутностей та інших основних елементів моделі записуються англійською мовою у форматі PascalCase.
7. Назви атрибутів та операцій записуються у форматі camelCase.
